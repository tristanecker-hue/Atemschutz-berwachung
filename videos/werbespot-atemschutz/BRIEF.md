# Werbespot ATEMSCHUTZ (Feuerwehr Zuchwil)

## Intent
High-End-Tech-Werbespot / Kinotrailer statt Software-Praesentation. Story: Einsatz -> Chaos -> Fragen -> App erscheint -> Trupp in Sekunden -> Live-Uebersicht -> App rechnet -> Meldungen -> Split-Screen -> PDF -> Finale -> Schlusstext.
Vollstaendiges Konzept: https://claude.ai/code/artifact/be0c17ea-5569-4660-9be2-e82bc3090bae

## Customizations
- Nur echte App-Funktionen (index.html v2.28): Trupp einteilen, Einstiegsdruck, Einsatz starten, Druckabfrage/ERFASSEN, Verbrauch bar/min, Rueckzugsdruck = Anmarschzeit x Verbrauch x 1.1 (min. 50), Umkehrdruck 50 bar, Abfrage alle 10 min, Meldungen mit Zeitstempel, Einsatzleiter-Ansicht, PDF-Protokoll, Uebungsmodus.
- App-Palette: #12151A / #1A1D21, Rot #D9483D, Orange #E8912D, Gruen #3E8E41; Fonts Oswald / Inter / IBM Plex Mono.
- Realszenen (Blaulicht, Brand, Trupp) als stilisierte Grafik-Platzhalter mit Shot-Label, spaeter durch Footage ersetzen.
